# Implementation Plan: Exercise Weapon Calculator

**Branch**: `feat/exercise-calculator` | **Date**: 2026-11-04 | **Spec**: [spec.md](./spec.md)

## Summary

Add a page at `/tools/exercise` that calculates charges, weapons, cost and time from static
Tibia Global data. Game rules are pure functions, and the page updates as the player types.

## Technical Context

**Language/Version**: TypeScript strict on Node 26
**Primary Dependencies**: Astro, React
**Storage**: browser storage for the last values, optional
**Testing**: Vitest for rules, Playwright for the page, both in CI
**Target Platform**: static site on modern mobile and desktop browsers
**Project Type**: web application
**Performance Goals**: results update with no perceptible delay
**Constraints**: no backend, no login, 375 px wide
**Scale/Scope**: one page, 8 vocation and skill pairs, 3 weapon types

Principle III says game data is generated by scripts. The few values here are hand-curated from
articles, because no source offers them in a usable format. They stay in one data file with their
sources and review date. **Exception justified**: a script would add more risk than these values.

## Project Structure

```text
src/
  data/exerciseWeapons.ts            # weapons, skill constants and review date
  domain/exerciseCalculator.ts       # pure rules
  domain/exerciseCalculator.test.ts
  components/ExerciseCalculator.tsx
  components/ExerciseCalculator.module.css
  pages/tools/exercise.astro
  data/tools.ts                      # adds the link on the home page
e2e/exercise.spec.ts
```

**Structure Decision**: follow the charm optimizer layout. Rules receive server data as a parameter
instead of importing it, so another server can be added later without rewriting them. This version
has no server selector.
